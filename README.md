# ScoutAPI (self-host image)

Public build home for:

```bash
docker pull ghcr.io/macrocontent/scout:latest
```

Product code is mirrored from the private MacroContent monorepo (`apps/scout`) so GHCR can stay anonymously pullable.

Docs: https://docs.macrocontent.dev/scout/self-hosted/install

Self-hosted tiers are capacity classes (deployments + workers). You operate the stack — Macro does not sell tiered premium support for self-host.
